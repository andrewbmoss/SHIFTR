Recordings

Recordings are kept in this browser until you delete them. Download CSV works while recording too. Each row has the PC's clock time, so it lines up with Zwift's activity file and your head unit's recording.

Run this page in its own window (drag the tab out of the tab bar) and leave that window open while riding; it can sit behind Zwift. Browsers put background tabs to sleep after about 5 minutes, which stops the logging. Also add the bridge's address under Chrome Settings > Performance > Always keep these sites active, or Edge Settings > System and performance > Never put these sites to sleep. If it does get closed or reloaded, it carries on where it left off, and anything older than 4 minutes is marked as a gap.
